## Do terminal pra live

Sou VTuber e dev. Gosto de aprender fazendo e mostrar o processo: o código que funcionou, o erro que levou mais tempo do que devia e a tentativa que virou corte.

Este é o espaço dos projetos, estudos e experiências que acompanham as lives. Tem programação, Linux, banco de dados e, entre um projeto e outro, gameplay e conversa com o chat.

## O que passa pela bancada

- **Python e Pygame:** experiências e jogos para aprender programando.
- **Banco de dados e SQL:** conceitos e consultas na prática.
- **Linux e tecnologia:** terminal, configurações e tentativas de dar uma segunda vida aos aparelhos.
- **Games:** uma partida para mudar de problema. Voltar para o lobby também faz parte.
